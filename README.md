# Student Manager

Невеликий навчальний сайт для студента. У ньому є:

- реєстрація і вхід у свій акаунт
- налаштування профілю студента
- розклад занять
- домашні завдання
- дедлайни
- нотатки
- дашборд з реальною статистикою по акаунту
- редагування записів після створення

## Стек

- `Python`
- `NiceGUI` для інтерфейсу
- `PostgreSQL` на Railway
